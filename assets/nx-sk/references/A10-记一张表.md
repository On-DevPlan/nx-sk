# A10 · 记一张表（table 字段）

> 要存「多行多列、每格有类型、可能有公式/合计」的数据时读这篇。
> 列结构固定、只是行数多的清单 → 用 `A11-记一份结构清单`，不要为了简单清单上 table。

## 一、先判断：table 还是 entrylist

| 问题 | table | entrylist |
| --- | --- | --- |
| 每条的列会不一样吗 | 会（结构归数据） | 不会（列在字段定义里） |
| 需要数字/日期/下拉/勾选类型 | 是 | 否，通常全是文本 |
| 需要公式列或表尾统计 | 是 | 否 |
| 只是「多组账号/链接」 | 不必 | 是 |

## 二、建字段

```bash
# 面板：条目页「＋ 添加字段」→ 类型选「表格」
# CLI：只给字段名；列可以之后再定，也可以随初始列一起给
nx-sk entry add-field <条目> --key tasks --label 任务表 --type table
```

`table` 的列定义**存在值里**，字段定义只提供「新建时的初始列」。所以同一条想多一列，不用改模板、也不影响别的条目。

## 三、写入

最小形状：

```json
{
  "columns": [
    {"key": "task", "label": "任务", "type": "text"},
    {"key": "hours", "label": "工时", "type": "number", "total": "sum"},
    {"key": "rate", "label": "单价", "type": "number"},
    {"key": "cost", "label": "费用", "type": "number", "formula": "hours * rate", "unit": "元"}
  ],
  "rows": [
    {"task": "写文档", "hours": 2, "rate": 100},
    {"task": "联调", "hours": 3, "rate": 120}
  ]
}
```

```bash
nx-sk entry update <条目> --set 'tasks={"columns":[…],"rows":[…]}' --dry-run
nx-sk entry update <条目> --data @table.json
```

- `rows` 也可单独给（列取初始列）；**有行没列**会报错，不能靠猜。
- 列 key 也是公式变量名；中文列名也能当变量（`工时 * 单价`）。
- 计算列（`formula`）不落盘，读时按声明顺序算；只能引用**前面**的列。
- 下拉列（`select`）必须给 `options`；勾选列用 `bool`。
- 空格子参与公式时按 `0 / false / ''`，要判「真没填」用 `isBlank(row.hours)`。

## 四、读

```bash
nx-sk entry table <条目> --field 任务表      # 只读这张表：数据 + 表尾合计 + 公式错误
nx-sk entry get <条目> --json                # values.tasks + tables.tasks（算好的现值）
```

`entry get --json` 里的 `tables` 是**现算结果**（含合计、计算列），与面板显示同源。

## 五、Web 上怎么改

- 列头悬停出现 `⋮`：改列名/类型/key/单位/默认值/统计/密文/选项/公式，左右插列、复制、删除。
- 表头末尾 `＋` 加列；表格底部「新建一行」加行。
- 拖表头搬列；拖行左侧 `⠿` 搬行，有插入线。
- 敏感列（`sensitive: true`）密文落盘；打码状态下不要拖行（短密码打码值相同会认错行）。

## 六、空与默认

| 写入 | 结果 |
| --- | --- |
| `--set tasks=` / `[]` / `{}` | 清空行；有初始列则保留空骨架 |
| `{"columns":[…],"rows":[]}` | 列齐、无行（算未填） |
| 全空行 | 自动剔除 |

公式语法、统计函数、错误对照全在 `B02-字段类型与格式`；这篇只讲怎么下手。

## 七、常见错

| 报错 | 改法 |
| --- | --- |
| 有 N 行数据却没有任何列 | 把 `columns` 一起写进值里 |
| 公式用了不存在的名字 | 列 key 打错，或那列还没加 |
| 引用自己/后面的计算列 | 把被引用的计算列往前挪 |
| 下拉值不在候选里 | 补 `options`，或把列类型改回 text |
| 数字列收到「两小时」 | 只写数字，单位放 label/unit |
