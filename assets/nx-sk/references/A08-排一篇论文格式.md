# A08 · 排一篇论文的格式（模板 / 硬指标 / 自检）

> 只保证格式一分不丢，不替用户写正文。规范：信息工程学院 2022 版（设计开发类）。

## 三条铁律

1. **格式是硬指标**：规范写「黑体四号不加粗」就照做，别按审美改。
2. **模板用脚本生成**：页边距 2.5cm / 行距 1.5 / 字号 10.5pt 这些数值手调必漏。
3. **交稿前两件事**：更新目录域、删掉全部批注。

## 拿到模板后的顺序

1. 改封面与标题页信息（学院 / 专业 / 学号 / 导师 / 届别 / 完成日期）。
2. 题目先过 20 字红线（见 B03 踩坑）。
3. 按「结构」一节填正文，每段对照「格式」一节。
4. 图表代码各留模板样例，照样式改，不新建样式。
5. 交稿前更新目录 → 查页码 → 删批注 → 打印预览。

## 格式硬指标（设计开发类 · 2022 版）

格式硬指标（设计开发类 · 2022 版）

> 全部数值取自《信息工程学院本科毕业论文（设计）撰写规范（2022-11）》【设计开发类】。
> 括号里的页码指该 PDF 的页脚页码（「本科开题报告、毕业论文格式和打印要求」p.8–12）。

### 页面

| 项目 | 值 |
| --- | --- |
| 纸型 | A4，单面打印 |
| 上边距 | 2.5 cm |
| 下边距 | 2 cm |
| 左边距 | 2.5 cm |
| 右边距 | 2 cm |
| 页眉 | **不加**；页眉处不得有横线 |
| 页脚 | 底端距离 1.5 cm |
| 页码 | 页脚居中，小五号 Times New Roman，阿拉伯数字 1、2、3；不写「第1页」「－1－」 |
| 页码范围 | 内页封面、目录、标题页**不编**；从标题页之后（正文第 1 页）起为 1 |
| 装订 | 左侧装订，学校统一硬皮封面 |

### 字体与行距

| 元素 | 字体 / 字号 | 其他 |
| --- | --- | --- |
| 论文题目 | 黑体三号（16 pt） | 居中 |
| 一级标题 | 黑体（西文 TNR）四号（14 pt） | **不加粗**，顶格，序号后空一格，单独占行，末尾无标点，标题前空一行 |
| 二级标题 | 黑体（西文 TNR）小四（12 pt） | 不加粗，顶格 |
| 三级标题 | 宋体（西文 TNR）小四（12 pt） | 不加粗，顶格 |
| 四级标题 | 不单独占行 | 用（1）（2）接排，按正文格式 |
| 正文 | 宋体小四（12 pt） | 西文与数字 TNR 小四；1.5 倍行距；段前段后 0；首行缩进 2 字符 |
| 图题 / 表题 | 黑体五号（10.5 pt） | 西文 TNR；居中 |
| 表内文字 | 宋体五号（10.5 pt） | 西文 TNR |
| 表注 | 宋体小五（9 pt） | 西文 TNR |
| 参考文献 | 宋体小四（12 pt） | 1.5 倍行距，悬挂缩进 2 字符 |

> 「小四」= 12 pt，「四号」= 14 pt，「三号」= 16 pt，「五号」= 10.5 pt，「小五」= 9 pt。
> 全文标准字距，不要用「加宽/紧缩」。

### 标题编号

- 一律阿拉伯数字：`1` → `1.1` → `1.1.1`，层级之间用**英文半角点号**。
- 原则上不超过 4 级；确实需要第 4 级时用（1）（2），不单独占行。
- 序号与标题之间**空一格**（`1 绪论`，不是 `1绪论`，也不是 `1. 绪论`）。
- 标题末尾不加标点，标题与后文之间不留空行——靠「标题前空一行」来分隔章节。

### 图

- 图题在**图的下方**，由「图号 + 空格 + 图名」组成：`图1 系统总体架构图`。
- **图与序号之间不空格**；序号全文连续（图1、图2…），不要写成 `图1-1`、`图1.1`。
- 插图排在**正文提及之后**；版式「嵌入型」、居中、首行不缩进。
- 白底黑字黑线；不加底纹与网格；文本框不加填充；四周不要大片空白。
- 图与正文上下各空一行。

### 表

- 表题在**表的上方**：`表1 知识条目表结构`，黑体五号，居中。
- **三线表**：不加左右边线；上下底为 1.5 磅粗实线；表头下为 1 磅细实线。
- 表内五号（中文宋体、西文 TNR）；表头简单明了，尽量不用斜线。
- 表格尽量不跨页；有表注时写在表底线下方**左侧**，宋体小五。
- 表格前后各空一行。

### 代码

- 自动生成的代码不要出现在论文里。
- 正文代码原则上不超过 **3/4 页**；超出就用伪代码或流程描述代替。
- 只保留难以用文字描述的核心代码；大段完整代码放附录。
- 按正文字体字号（宋体小四）；缩进 2 或 4 空格，同级起止同列；行内注释对齐；
  一行过长可换行，换行后与上行开头对齐。
- 讲解以**思想与流程**为主，不能写成「点这里、再点那里」的操作过程。

### 参考文献

| 项目 | 要求 |
| --- | --- |
| 数量 | ≥15 篇，其中外文 ≥2 篇 |
| 时效 | 以近 5 年公开发表的期刊文献为主，必须亲自读过，不得转引 |
| 著录标准 | GB/T 7714-2015，顺序编码制 |
| 正文标注 | 引用处文字**右上角上标** `[X]`，按出现先后连续编号；同一文献只用一个编号；标在句号之前 |
| 排序 | 文后按正文标注的序号依次列出，序号左顶格 |
| 版面 | 小四，1.5 倍行距，悬挂缩进 2 字符 |
| 标点 | 一律英文半角、标点后空一格；每条以实心点结束 |
| 作者 | ≤3 位全列；>3 位只列前 3，中文加「等」，西文加「et al.」 |

文献类型标识：期刊 `[J]`、专著 `[M]`、学位论文 `[D]`、会议论文集 `[C]`、
报纸 `[N]`、报告 `[R]`、标准 `[S]`、专利 `[P]`、论文集析出 `[A]`、电子资源 `[EB/OL]`。

### 摘要与关键词

- 中文摘要 250–300 字，**不分段**；按「【目的】…；【方法】…；【结果】…；【结论】…」组织。
- 摘要里不出现公式、图表，不标引用编号。
- 关键词 3–5 个，能覆盖主要内容，按外延由大到小，分号分隔。
- 英文题目、作者、摘要、关键词与中文一一对应；题目实词首字母大写（介词除外）。

### 字数

- 论文一般不少于 **8000 字**，尽量 25 页以上。
- 开题报告不少于 **3500 字**。



## 结构与装订

结构与装订（设计开发类）

### 论文由哪几块组成

```
内页封面
目录（只提取到三级标题）
标题页：中文题目 → 专业+姓名 → 导师 → 摘要 → 关键词
        → 英文题目 → 英文作者 → Supervisor → Abstract → Key words
正文：1 绪论 … 6 结论
参考文献（另起一页）
致谢（另起一页）
附录（另起一页）
```

内页封面、目录、标题页**不编页码**；标题页之后从 1 开始编。

### 正文该有什么（设计开发类）

规范给的骨架是：**开发背景 → 相关方法与技术 → 总体功能结构设计 → 重点模块设计与实现 →
系统测试 → 小结**。落到 6 章，推荐：

| 章 | 内容 | 评审在看什么 |
| --- | --- | --- |
| 1 绪论 | 研究背景与意义、国内外研究现状、主要研究内容与论文结构 | 你知不知道这个题为什么值得做 |
| 2 相关方法与技术 | 涉及的理论、算法、系统环境、开发工具 | 每种技术在**你的项目里**起什么作用，不是教科书式罗列 |
| 3 需求分析与总体设计 | 需求、功能结构、模块结构、数据结构、实施架构 | 有没有用软件工程方法做设计，图能不能看懂 |
| 4 重点模块详细设计与实现 | 挑 2–4 个特色模块讲透 | 「重点」和「特色」；不要平铺所有模块 |
| 5 系统测试与结果分析 | 测试方法、流程、用例选取、结果分析 | 数据是否可信、结论是否由数据支撑 |
| 6 结论 | 主要结果、创新点、不足与后续工作 | 有没有自己的判断，别写成摘要的复制 |

顺序不能颠倒：没有需求与设计，直接讲实现，会被问「你凭什么这么设计」。

### 各部分写作要求

- **题目**：体现研究对象、研究内容与要解决的问题；原则上 ≤20 字；必要时加副标题。
- **中文摘要**：250–300 字，不分段，按【目的】【方法】【结果】【结论】组织；不出现公式图表、
  不标引用编号。
- **关键词**：3–5 个，分号分隔，外延由大到小。
- **英文部分**：与中文一一对应；题目实词首字母大写（介词、连词除外）。
- **参考文献**：≥15 篇、外文 ≥2 篇，近 5 年期刊为主；正文必须有引用，按出现顺序编号。
- **致谢**：另起一页，「致谢」黑体四号居中，200 字以上。
- **附录**：另起一页，格式参照正文；放原始数据、数据库详细结构表、运行截图、程序全文。

### 开题报告 vs 毕业论文：别混用一套样式

| 元素 | 开题报告 | 毕业论文 |
| --- | --- | --- |
| 一级标题 | 黑体小四 | **黑体四号** |
| 二级标题 | 宋体小四 | **黑体小四** |
| 三级标题 | 宋体小四 | 宋体小四 |
| 四级标题 | 不设；必要时（1）（2）接排 | 同左 |
| 正文 | 宋体小四 | 宋体小四 |
| 图表标题 | 黑体五号 | 黑体五号 |
| 表内文字 | 宋体五号 | 宋体五号 |
| 参考文献 | **五号** | **小四** |
| 字数 | ≥3500 字 | ≥8000 字，尽量 25 页以上 |
| 页码 | 每页都编 | 封面/目录/标题页不编，正文起为 1 |

开题报告正文结构：题目 → 立题依据（项目背景 / 国内外研究进展 / 设计目的与意义）→
研究的主要内容及预期目标 → 设计实现方案（系统分析与设计 / 技术路线）→ 进度安排 → 参考文献。
导师意见不少于 50 字。

### 装订顺序（8 项，别漏）

1. 论文（设计）答辩记录及成绩评定表
2. 本科毕业论文（设计）导师评分表
3. 本科毕业论文（设计）答辩评分表
4. 开题报告答辩记录表
5. 开题报告
6. 选题更改申请表（仅改题时）
7. 新的开题报告（改题后）
8. 论文内页封面、目录、正文

左侧装订，用学校统一发放的硬皮封面。

### 时间红线

- 进度：从选导师当年 **11 月**到毕业年份 **3、4 月**；分阶段、阶段之间不能断。
- **导师意见签署日期必须早于答辩日期**——答辩后再找导师签，会被退回。
- **封面完成日期必须晚于答辩委员会日期**。
- 成绩构成：导师审阅 50% + 答辩 50%（有学生互评的专业为 40% + 10% + 50%）。
