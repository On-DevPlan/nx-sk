# A13 · 让用户逐条确认（grill 字段）

> 当你的理解会影响后续实现、需要用户明确拍板时，用 grill 把问题写成条目字段。
> 不是「AI 说一段、用户回一句可以」——用户的否定、理由、自由补充都要留在数据里。

## 一、工作流

1. **AI 写问题**：把「我准备怎么做、为什么这么问」写进 grill 字段；
2. **用户在 Web 逐题答**：单选/多选/填空/确认，每题可写备注；
3. **用户点「确认并回写」**：字段里落下 `ack`；
4. **agent 只认 `ack.status`**：`acknowledged` 才代表拍板，`pending` 继续等。

## 二、写问题

最小形状只需要 `questions`：

```json
{
  "title": "周报范围对齐",
  "prompt": "用户原话放这里",
  "questions": [
    {
      "id": "scope",
      "type": "single",
      "title": "范围包含哪些？",
      "detail": "为什么问：两种做法工作量差一倍",
      "options": [
        {"value": "core", "label": "只做核心"},
        {"value": "all", "label": "全做", "recommended": true}
      ]
    },
    {
      "id": "checks",
      "type": "multi",
      "title": "验收看哪些证据？",
      "options": ["测试全绿", "手动验证"]
    },
    {
      "id": "note",
      "type": "text",
      "title": "还有什么必须确认？",
      "required": false
    }
  ]
}
```

```bash
nx-sk entry update <条目> --set 'grill={"title":"…","questions":[…]}' --dry-run
nx-sk entry update <条目> --data @questions.json
```

- 四种题型：`single` / `multi` / `text` / `confirm`（别名 `radio` / `checkbox` / `textarea` / `bool`）。
- **默认必答**；写 `required: false` 或 `optional: true` 才是可选。
- 每个问题把「为什么问」写进 `detail`；不要只给一个没有上下文的问题。
- `answer` 形状：单选是候选 `value` 字符串；多选是数组；确认是布尔；填空是字符串。

## 三、读回确认状态

```bash
nx-sk entry get <条目> --json
```

看 `values.grill.ack`：

```json
{ "status": "acknowledged", "at": "…", "by": "web", "answered": 3, "total": 3 }
```

- `acknowledged` = 用户已确认，可以按答案继续。
- `pending` = 还有必答题没答 / 用户改过答案，**不能当成已确认**。
- 必答没答完时，服务端会把伪造的 `acknowledged` 强制退回 `pending`。
- 改任何一格都会退回 `pending`，需要重新确认。

## 四、Web

- 条目里只有一个很小的状态按钮（`N/M 已确认`）；点开是整页面板，也可切侧边/居中。
- 逐题回答 + 每题备注；必答全齐才解锁「确认并回写」。
- 底部有全局自由补充；确认后回写整份 grill。

## 五、纪律

- **不要替用户答**：`answer` 只能来自用户操作；AI 可以先填候选，但不能写 `ack`。
- **不要用 grill 藏信息**：问题要短、可回答；背景写 `intro/prompt/detail`，不要塞进标题。
- **确认后别静默改问题**：改了问题或答案就重新确认，旧 ack 不作数。
- grill 不能当表格列；不引用附件。

## 六、常见错

| 现象 | 原因 | 改法 |
| --- | --- | --- |
| 面板点不开 | 字段值不是合法 GrillDoc | 用 `--json` 读回，按 `questions` 形状重建 |
| 确认按钮一直是灰的 | 有必答题没答 | 补答，或把该题设 `required: false` |
| AI 以为已确认 | 只看「字段里有问题」 | 必须看 `ack.status === acknowledged` |
| 改完答案没生效 | 只改了界面没保存 | 走面板「确认并回写」，不要手改 JSON 后不保存 |
