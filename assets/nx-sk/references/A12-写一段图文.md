# A12 · 写一段图文（md 字段）

> 要写「说明 + 截图混排」的正文时读这篇：SOP、报错复现、会议纪要、带图待办。
> 纯长文本用 `textarea`；二进制原件挂条目用 `file`（A05）。

## 一、值是什么

- `md` 字段的值 = **一段 markdown 字符串**，不是文件路径。
- 本地图片用 `![说明](f_xxx)` 引用附件库；外链图用 `![说明](https://…)`（要联网，不进附件库）。
- 正文即真相：待办勾选就是改正文里的 `[x]`，没有第二份勾选状态。

## 二、图片先进附件库

```bash
# 保留原件（推荐）
nx-sk file add --path "D:/截图/报错.png" --copy --json
# → {"id":"f_xxx", …}，把 id 写进正文
```

```markdown
### 复现步骤

1. 打开控制台
2. 点击「部署」

![报错现场](f_xxx)
```

`file add` 默认**移动**原件；用户文件还在原地就加 `--copy`。

## 三、写入

```bash
nx-sk entry update <条目> --set 'body=### 背景

一句话。
- [ ] 待办一
- [x] 待办二

![现场](f_xxx)' --dry-run

nx-sk entry update <条目> --data @body.json
```

Windows 下多行值建议用 `--data @file.json`（JSON 转义更稳），不要跟 shell 引号搏斗。

## 四、读

```bash
nx-sk entry get <条目>          # 本地图片会还原成「[图片: 说明] 本地路径」，agent 可直接读文件
nx-sk entry get <条目> --json   # values.body 是原始 markdown
```

## 五、Web

- 编辑器支持 **Ctrl+V 粘贴截图**、拖入图片、从附件库选图；上传后自动插入引用。
- 预览按标准 markdown 渲染：标题/列表/表格/代码块；裸 IP 点击复制、裸域名点击打开。
- 待办 `- [ ]` 在预览里可点勾；**点完要保存**，否则只改了界面没写回条目。
- 长文在块布局里按内容撑高，不在块内滚。

## 六、写法规矩

- 结构靠空行分段；单个换行会保留成 `<br>`。
- 图片说明写人话（三个月后能认出是哪张图）。
- **不要在 md 里写密码**：md 是明文渲染；敏感内容走 `secret`/`sensitive` 字段。
- 「一串要做的事」用 `- [ ]`，不要用 `1./2.` 序号（序号只是字，不可点）。

## 七、常见错

| 现象 | 原因 | 改法 |
| --- | --- | --- |
| 图片不显示 | 用了本地路径 / 文件名，不是附件 id | 先 `file add`，正文写 `![](f_xxx)` |
| 粘贴图片没进库 | 只在编辑器里预览，没触发上传 | 用 Ctrl+V 后确认出现 `f_` 引用；或先 `file add` |
| 勾选后刷新又变回未完成 | 没保存 | 勾完点「保存」 |
| 外链图打不开 | 需要联网，且对方允许外链 | 重要图先下载再 `file add --copy` |
