# 格式硬指标（设计开发类 · 2022 版）

> 全部数值取自《信息工程学院本科毕业论文（设计）撰写规范（2022-11）》【设计开发类】。
> 括号里的页码指该 PDF 的页脚页码（「本科开题报告、毕业论文格式和打印要求」p.8–12）。

## 页面

| 项目 | 值 |
| --- | --- |
| 纸型 | A4，单面打印 |
| 上边距 | 2.5 cm |
| 下边距 | 2 cm |
| 左边距 | 2.5 cm |
| 右边距 | 2 cm |
| 页眉 | **不加**；页眉处不得有横线 |
| 页脚 | 底端距离 1.5 cm |
| 页码 | 页脚居中，小五号 Times New Roman，阿拉伯数字 1、2、3；不写「第1页」「－1－」 |
| 页码范围 | 内页封面、目录、标题页**不编**；从标题页之后（正文第 1 页）起为 1 |
| 装订 | 左侧装订，学校统一硬皮封面 |

## 字体与行距

| 元素 | 字体 / 字号 | 其他 |
| --- | --- | --- |
| 论文题目 | 黑体三号（16 pt） | 居中 |
| 一级标题 | 黑体（西文 TNR）四号（14 pt） | **不加粗**，顶格，序号后空一格，单独占行，末尾无标点，标题前空一行 |
| 二级标题 | 黑体（西文 TNR）小四（12 pt） | 不加粗，顶格 |
| 三级标题 | 宋体（西文 TNR）小四（12 pt） | 不加粗，顶格 |
| 四级标题 | 不单独占行 | 用（1）（2）接排，按正文格式 |
| 正文 | 宋体小四（12 pt） | 西文与数字 TNR 小四；1.5 倍行距；段前段后 0；首行缩进 2 字符 |
| 图题 / 表题 | 黑体五号（10.5 pt） | 西文 TNR；居中 |
| 表内文字 | 宋体五号（10.5 pt） | 西文 TNR |
| 表注 | 宋体小五（9 pt） | 西文 TNR |
| 参考文献 | 宋体小四（12 pt） | 1.5 倍行距，悬挂缩进 2 字符 |

> 「小四」= 12 pt，「四号」= 14 pt，「三号」= 16 pt，「五号」= 10.5 pt，「小五」= 9 pt。
> 全文标准字距，不要用「加宽/紧缩」。

## 标题编号

- 一律阿拉伯数字：`1` → `1.1` → `1.1.1`，层级之间用**英文半角点号**。
- 原则上不超过 4 级；确实需要第 4 级时用（1）（2），不单独占行。
- 序号与标题之间**空一格**（`1 绪论`，不是 `1绪论`，也不是 `1. 绪论`）。
- 标题末尾不加标点，标题与后文之间不留空行——靠「标题前空一行」来分隔章节。

## 图

- 图题在**图的下方**，由「图号 + 空格 + 图名」组成：`图1 系统总体架构图`。
- **图与序号之间不空格**；序号全文连续（图1、图2…），不要写成 `图1-1`、`图1.1`。
- 插图排在**正文提及之后**；版式「嵌入型」、居中、首行不缩进。
- 白底黑字黑线；不加底纹与网格；文本框不加填充；四周不要大片空白。
- 图与正文上下各空一行。

## 表

- 表题在**表的上方**：`表1 知识条目表结构`，黑体五号，居中。
- **三线表**：不加左右边线；上下底为 1.5 磅粗实线；表头下为 1 磅细实线。
- 表内五号（中文宋体、西文 TNR）；表头简单明了，尽量不用斜线。
- 表格尽量不跨页；有表注时写在表底线下方**左侧**，宋体小五。
- 表格前后各空一行。

## 代码

- 自动生成的代码不要出现在论文里。
- 正文代码原则上不超过 **3/4 页**；超出就用伪代码或流程描述代替。
- 只保留难以用文字描述的核心代码；大段完整代码放附录。
- 按正文字体字号（宋体小四）；缩进 2 或 4 空格，同级起止同列；行内注释对齐；
  一行过长可换行，换行后与上行开头对齐。
- 讲解以**思想与流程**为主，不能写成「点这里、再点那里」的操作过程。

## 参考文献

| 项目 | 要求 |
| --- | --- |
| 数量 | ≥15 篇，其中外文 ≥2 篇 |
| 时效 | 以近 5 年公开发表的期刊文献为主，必须亲自读过，不得转引 |
| 著录标准 | GB/T 7714-2015，顺序编码制 |
| 正文标注 | 引用处文字**右上角上标** `[X]`，按出现先后连续编号；同一文献只用一个编号；标在句号之前 |
| 排序 | 文后按正文标注的序号依次列出，序号左顶格 |
| 版面 | 小四，1.5 倍行距，悬挂缩进 2 字符 |
| 标点 | 一律英文半角、标点后空一格；每条以实心点结束 |
| 作者 | ≤3 位全列；>3 位只列前 3，中文加「等」，西文加「et al.」 |

文献类型标识：期刊 `[J]`、专著 `[M]`、学位论文 `[D]`、会议论文集 `[C]`、
报纸 `[N]`、报告 `[R]`、标准 `[S]`、专利 `[P]`、论文集析出 `[A]`、电子资源 `[EB/OL]`。

## 摘要与关键词

- 中文摘要 250–300 字，**不分段**；按「【目的】…；【方法】…；【结果】…；【结论】…」组织。
- 摘要里不出现公式、图表，不标引用编号。
- 关键词 3–5 个，能覆盖主要内容，按外延由大到小，分号分隔。
- 英文题目、作者、摘要、关键词与中文一一对应；题目实词首字母大写（介词除外）。

## 字数

- 论文一般不少于 **8000 字**，尽量 25 页以上。
- 开题报告不少于 **3500 字**。
