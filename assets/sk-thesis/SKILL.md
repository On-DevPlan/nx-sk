# sk-thesis · 毕业论文格式与结构

**这份 skill 不写论文，只保证「格式一分不丢」。**

规范里真正会扣分的从来不是文笔，是这些：页边距差 2 毫米、一级标题加粗了、图题写成「图 1」、
（1）（2）用了 Word 自动编号、目录没更新、参考文献标点用了全角。每一条都小，但每一条都会被
格式审查挑出来。

## 三条铁律

1. **格式是硬指标，不是审美。** 规范写「黑体四号不加粗」就照做，别觉得加粗更好看。
   规范写「图1 名称」就一个空格，别自己加空格。
2. **模板用脚本生成，不要手调。** 页边距 2.5 cm、行距 1.5 倍、字号 10.5 pt 这些数值，
   手调只能保证这一份对；脚本能逐条核对，改一处只改一行。
3. **交稿前必做两件事**：更新目录域、删除所有批注（模板里带了 23 条格式提示）。

## 这里有什么

| 路径 | 用途 |
| --- | --- |
| `templates/毕业论文模板-设计开发类.docx` | 成品模板：封面 / 目录 / 标题页 / 正文 / 参考文献 / 致谢 / 附录，样式全部按规范预设 |
| `scripts/make_thesis_template.py` | 生成上面这份模板；改格式只改这里 |
| `references/10-format.md` | 格式硬指标速查（页面、字体、标题、图表、参考文献、页码） |
| `references/20-structure.md` | 章节结构、各部分写作要求、开题与论文的差异、装订顺序 |
| `references/30-pitfalls.md` | 真实踩过的坑（含开题报告里已经犯的几条） |

本机 nx-sk 里的同款资料：`nx-sk section get thesis`（栏目「毕业论文」，含全部硬指标与自检清单）。

## 生成 / 重新生成模板

```bash
# 本机 managed venv 已装 python-docx
~/.workbuddy/binaries/python/envs/default/Scripts/python.exe \
  assets/sk-thesis/scripts/make_thesis_template.py \
  --out assets/sk-thesis/templates/毕业论文模板-设计开发类.docx
```

模板里每个关键位置都挂了 Word 批注（封面、目录、摘要、各级标题、图表、代码、参考文献、致谢），
说明「这里必须是什么格式」。**提交前按「审阅 → 删除 → 删除文档中的所有批注」清掉**，
否则打印时会带出批注气球。

## 拿到模板后的顺序

1. 先改封面与标题页的个人信息（学院 / 专业 / 学号 / 导师 / 届别 / 完成日期）。
2. **题目先过一遍 20 字红线**（见 `30-pitfalls` 第 1 条）。
3. 按 `references/20-structure.md` 的章节骨架填正文；每写一段对照 `10-format.md`。
4. 图、表、代码各留一个样例在模板里，照它的样式改，不要新建样式。
5. 交稿前：右键目录 → 更新整个目录 → 检查页码从标题页的 1 开始 → 删批注 → 打印预览。

## 与开题报告的区别

开题报告的标题字号与论文**不同**（一级黑体小四、二三级宋体小四），参考文献是五号；
两者别混用同一套样式。详见 `references/20-structure.md` 的对照表。
